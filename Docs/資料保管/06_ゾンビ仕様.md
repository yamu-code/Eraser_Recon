# 06 ゾンビ仕様（AI・感知・能力値）

- 版数：v1.4
- 最終更新：2026-09-26
- 関連資料：[01_制作方針.md](01_制作方針.md) / [04_武器仕様.md](04_武器仕様.md) / [05_ゾンビアニメーション仕様.md](05_ゾンビアニメーション仕様.md)
- §1〜§14 はユーザーが定めたゾンビ仕様を整理したもの。§15 はアニメーション制作との関係。
- **数値（特に能力値）は、ゲーム制作を進めながら調整する。** アニメーションは、ここの数値を基準に作り、数値が変わったら再生速度などで合わせる。

## 1. 基本コンセプト
- ゾンビは、感染による後遺症で「眠っている状態」から始まる存在。
- 視覚への依存は低く、主に聴覚と嗅覚（血）でプレイヤーを感知する。
- プレイヤーの行動によって、覚醒・追跡・攻撃を行う。
- 「気づいたらいる」恐怖を重視する。「見えていないから安全」ではなく「見えていないからこそ危険」というゲーム性にする。

## 2. 状態 AI（全ゾンビ共通）

| 状態 | 内容 |
|---|---|
| Sleep（眠り） | 初期状態。地面に倒れている。音・血・気配などに反応する |
| Half Awake（半覚醒） | 完全には覚醒していない。ゆらゆら歩き、ふらつく。攻撃はしない |
| Patrol（徘徊） | プレイヤーを認識していない。目的なく移動したり、周囲で行動したりする |
| Alert（覚醒） | プレイヤーを認識し、プレイヤーの方向へ反応する |
| Chase（追跡） | プレイヤーを追跡する |
| Attack（攻撃） | 攻撃準備から攻撃動作を行う |
| Lost（見失い） | プレイヤーを見失った。最後に感知した位置の周辺を探索し、一定時間後に徘徊または所定の位置へ戻る |

- 状態遷移の基本構造は全タイプ共通。タイプごとの差は、性質・能力値・感知性能・行動傾向で表現する。
- 未感知の間は全タイプ共通の徘徊速度で行動し、プレイヤーを認識した後にタイプごとの性能差を発揮する。

## 3. 覚醒
- プレイヤーの接近、または音・血・気配などをきっかけに覚醒する。
- 特定のエリアでは、複数体が同時に覚醒する。
- 他のゾンビが倒されたことをきっかけに、連鎖して覚醒する場合がある。
- 一部の個体はランダムで覚醒する。
- 覚醒と反応の性能はゾンビのタイプによって異なる。

## 4. 感知システム
- 視覚への依存は低い。聴覚でプレイヤーの行動を、嗅覚で血を感知する。
- 音と匂いは独立して判定する。範囲を合算も乗算もせず、**広い方を最終的な感知範囲とする**。
- 大きな音ほど遠くのゾンビに感知されやすい。
- プレイヤーがダメージを受けると、血による感知範囲が広がる。
- 感知性能はゾンビのタイプによって異なる。

## 5. 音

- プレイヤーが出した音を感知する。音が大きいほど感知範囲が広い。感知範囲は音の種類ごとに設定する。
- 出した音は一定時間残る。残る時間は、音の種類と大きさによって異なる。

| プレイヤーが出す主な音 | 大きさの順 |
|---|---|
| 発砲（プレイヤーの通常音の中で最大） | 1 |
| ダッシュ | 2 |
| 通常歩行 | 3 |
| 武器切替 | 4 |
| 忍び歩き | 5 |
| 呼吸音 | 別枠（§6） |

## 6. 呼吸音
- 単独の感知要素として管理する。感知範囲は 1.5m で、呼吸音だけでもゾンビに感知される。
- 呼吸音が出ている間は、足音などの今の音の感知範囲に +1.5m する。
- ダッシュを始めてから2.0秒後に発生する（スタミナ・疲労状態仕様で確定）。疲労状態の間も発生する。基本の継続時間は5.0秒。プレイヤー側では「激しい呼吸」と呼ぶ演出と同じもの。
- 立ち止まっても、解除条件を満たすまで続く。ダッシュをやめて通常歩行や忍び歩きに移っても、呼吸音が続いている間は +1.5m を維持する。

| 状況 | 解除条件 |
|---|---|
| ダッシュをやめたとき | ダッシュをやめてから5秒経過を優先する。5秒の時点でスタミナが70未満なら継続し、スタミナが70に達した時点で解除する |
| 疲労状態でダッシュをやめたとき | スタミナが70に達することを優先する。70に達した時点で5秒経っていなければ継続し、5秒経った時点で解除する |

- **解除の統一ルール（2026-09-26 確定）**：「5秒経過」かつ「スタミナ70以上」かつ「疲労状態でない」ときに解除する。5秒は、最後にダッシュを終えた時点から数える。疲労状態になった場合は、疲労状態になった瞬間から数える（回避の連続などで、ダッシュせずに疲労状態になった場合も同じ）。途中でもう一度ダッシュしたら、5秒を数え直す。
- ダッシュを疲労状態ぎりぎりでやめた場合など、残りスタミナと移動の仕方（歩く・忍び歩き・止まる）によって、5秒とスタミナ70のどちらが後から満たされるかが変わる。

## 7. 匂い（血）
- プレイヤーの血の匂いを感知する。HP が減るほど感知範囲が広くなる。
- 基本状態は「HP 満タン・シールドなし」。
- シールドには血の匂いを抑える効果があり、「HP 満タン・シールドあり」では基本状態より感知範囲が小さくなる。
- 「シールドなし・HP 1%」が最大の感知範囲。
- 血の匂いは一定時間残り、時間とともに感知範囲が小さくなる。

## 8. 遮蔽物
- 壁やドアによって音と匂いが弱まる。完全には遮断されない。
- 弱まる量は遮蔽物の種類と数で変わる。音と匂いは別々に判定する。
- 一定以上の遮蔽物を挟むと、プレイヤーを見失う。

## 9. 未感知時の行動
- プレイヤーに気付いていなくても、空間の中で行動する。完全に静止しているとは限らない。
- 行動の例：徘徊する、咀嚼する、壁を叩く、ドアにぶつかる、他のゾンビと干渉する、立ち止まる、周囲を見回す、しばらくその場に留まる。

## 10. 足音・移動音
- ゾンビは移動時に足音を出す。足音は遮蔽物越しでも聞こえ、距離と遮蔽物で小さくなる。
- 足音の大きさ・間隔・特徴から、ゾンビの存在や種類を推測できるようにする。

| タイプ | 足音 |
|---|---|
| ノーマル | 標準的 |
| 強化型 | ノーマルよりやや力強い |
| 反応型 | 比較的小さい |
| タンク型 | 特に重く大きい |
| 動物 | 人型とは異なる移動音 |
| 遠距離型 | 移動音に加えて、特徴的な攻撃準備音などを設定できる |

- 徘徊時：速度は全ゾンビ共通で 0.40m/秒。足音の音量は小、間隔は1.0秒。距離と遮蔽物による減衰あり。タイプ別の足音の詳細は未設定。

## 11. 追跡・見失い
- プレイヤーを認識すると追跡状態へ移る。感知したプレイヤーの位置を基準に追跡し、プレイヤーが動くと追跡方向を更新する。
- 距離を詰めて攻撃範囲へ近づく。追跡性能と追跡を続ける性能はタイプによって異なる。
- 遠距離型は、一定の適正距離を保つように行動する。
- 見失う条件：一定距離以上離れる／壁やドアなどの遮蔽物で感知できなくなる／音や血の匂いが時間経過で消える。
- 見失ったら Lost 状態へ移り、最後に感知した位置の周辺を探索する。一定時間後に徘徊または所定の位置へ戻る。再び感知したら追跡を再開する。

## 12. 攻撃

### 12-1 通常攻撃（人型）
- 近接攻撃（引っ掻き）。攻撃射程に入ると攻撃モーション（攻撃準備 → 踏み込み＋引っ掻き）を始める（D-47）。
- 攻撃射程は「攻撃モーションを始める距離」。腕の届く距離は約0.8m のため、攻撃動作の踏み込みで距離を詰める。踏み込み距離はプレイヤーとの距離に合わせて伸縮する（05 §1-5）。
- 攻撃準備中にプレイヤーが離れても、準備時間はリセットされない。準備中はダメージ判定を行わない。
- 攻撃動作を行ったら、命中・空振りに関係なく攻撃後クールタイムが発生する。クールタイム中は、構え直したり、周囲をうろちょろ動いたりする。

### 12-2 特殊攻撃：噛みつき
- プレイヤーとの距離が一定以下になると、掴みモーションへ移る。
- 掴みに成功すると噛みつく。プレイヤーは特定の入力で抵抗でき、成功するとゾンビを吹き飛ばして噛みつきを回避する。
- 抵抗の受付時間は約2秒（D-37）。噛みつきの後は、攻撃後クールタイムを適用する。
- 発生条件はゾンビのタイプによって異なる場合がある。噛みつきを行うタイプは 05 §1-1-2 のとおり（反応型のカエルは噛みつかない）。
- 優先順位（D-46）：攻撃準備中は掴みに割り込まず、そのまま引っ掻く。それ以外の状態でプレイヤーが 0.60m 以内に入ったら、掴みを優先する。

### 12-3 動物ゾンビの攻撃
- 基本攻撃は突進、または突進しての噛みつき。プレイヤーが4m以内に入ると突進攻撃のモーションを始める。
- 人型とは異なる攻撃モーションを使う。小型・高速の特性を活かして奇襲する。

### 12-4 攻撃判定
- 攻撃方向は8方向（前・後・左・右・左前・右前・左後・右後）を基準とする。
- 8方向は「命中判定の瞬間に、プレイヤーがゾンビから見てどの方向にいるか」の区分として使い、攻撃ごとに命中する方向を指定する（D-48）。ゾンビは攻撃準備の前半でプレイヤーの方へ向き、最後の約1秒は向きを固定する。
- 攻撃方向と攻撃距離の両方を満たした場合に命中する。
- 判定は、攻撃モーション中の指定したタイミングで発生する。

## 13. 被ダメージ・復帰
- 攻撃を受けるとダメージを受ける。一定の攻撃ではノックバックし、攻撃の種類によってノックバック量が異なる。
- 一定の条件では転倒する。ノックバック中は通常の行動ができない。
- ノックバックや転倒の後は、一定時間が経つと復帰する。
- ノックバック耐性はタイプによって異なる。完全に倒されたゾンビは復活しない。

## 14. タイプと数値（初期値。制作中に調整する）

### 14-1 基本ゾンビ（共通の基準値）
| 項目 | 値 |
|---|---|
| 攻撃 | 近接（引っ掻き）、射程 3.0m 以内 |
| 攻撃準備 / 攻撃後クールタイム | 3秒 / 3秒 |
| ダメージ | 30 |
| 覚醒後の移動速度 | 0.65m/秒 |
| 噛みつき | 発動距離 0.60m 以内、動作時間 約1.5秒 |
| 感知距離 / 見失う距離 | 10m 以内 / 10m 以上 |
| 見失う遮蔽物 | 壁・ドアを2枚以上挟む |
| 徘徊速度（全タイプ共通） | 0.40m/秒 |

### 14-2 タイプ別
| タイプ | 特徴 | HP | 移動速度 | 攻撃力 | 攻撃射程 | ノックバック耐性 | 攻撃後クールタイム |
|---|---|---|---|---|---|---|---|
| ① ノーマル | 全ての基準。標準的な能力・感知性能・行動傾向 | 100 | 0.65 | 30 | 3m | 20% | 3秒 |
| ② 強化型 | ノーマルをバランスよく強化 | 150 | 0.85 | 45 | 3m | 50% | 5秒 |
| ③ 反応型 | 音と血への反応に特化したクリーチャー型（最初は二足歩行のカエル。引っ掻きはするが噛みつきは無い。攻撃射程 4.5m は跳んで飛びかかる）。覚醒と反応が速い。音と匂いの感知範囲が、プレイヤーの今の範囲 +3m | 80 | 0.65 | 30 | 4.5m | ― | 3秒 |
| ④ タンク型 | HP が高く、ノックバックされにくい重量型。器用な動きが苦手。噛みつきは無い（D-57） | 250 | 0.45 | 50 | 1.5m | 90% | 5秒 |
| ⑤ 動物 | 犬・鳥・虫の3種類（ゲーム仕様書 §4.16）。小型・高速の奇襲型。ナイフなどの近接攻撃で即死させられる。人型と異なる移動特性。群れで行動する場合がある。攻撃後に大きな隙が出る場合がある。突進速度 2.0m/秒、4m 以内で突進を始める | 50 | 0.65 | 20 | 4m | ― | 3秒 |

### 14-3 体術
- 体術はゾンビのタイプごとにアニメーションを作り、ゾンビごとに発動するアニメーションを切り替える（D-49）。
- 崩れた部位と技の対応（04 §7）は全タイプ共通。

## 15. アニメーション制作との関係
- アニメーションの仕様は 05 に書く。ここで決まった速度・射程・時間は、05 のアニメーションの長さと移動量の基準になる。
- 数値を変えたときに作り直しにならないよう、05 では「再生速度で時間に合わせる」「ルートモーションの移動量をスクリプトで伸縮する」方式を基本にする。
