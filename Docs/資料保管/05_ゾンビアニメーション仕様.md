## 1. 共通方針

### 1-1 リグとタイプごとのアニメーションの分け方
- 人型のゾンビは **Unity Humanoid** のリグにする。
  - プレイヤーと骨格の構造を揃えると、体術・掴み・噛みつきの同期アニメーションを Blender で両方同時に作りやすい。
  - 体型の違う人型（ノーマル・強化型・タンク型など）でアニメーションを共用できる。
- タイプごとの差は、共通のアニメーションを Animator Override Controller で部分的に差し替えて表現する。

### 1-1-2 タイプごとの攻撃と体術の対応（D-49）

| タイプ | 引っ掻き | 掴み・噛みつき | 体術を受ける動作 |
|---|---|---|---|
| ① ノーマル | あり | あり | 人型標準のセット（⑰） |
| ② 強化型 | あり | あり | 人型標準のセットを共用（体格が同じため） |
| ③ 反応型（カエル） | あり（飛びかかり） | **なし** | カエル専用のセット。発動条件（崩れた部位と技の対応）はゾンビと同じ |
| ④ タンク型 | あり | なし（D-57） | タンク専用のセット |
| ⑤ 動物 | 突進・突進噛みつき | 突進噛みつき（掴みはしない） | 動物専用のセット |
| ⑥ 遠距離型 | 毒を吐く（近距離は苦手） | なし（D-57） | 人型標準のセットを共用 |

- 体術のアニメーションはタイプごとに作り、どのゾンビに体術をかけたかで、プレイヤーとゾンビの両方の再生するアニメーションを切り替える。
  - プレイヤー側の体術（03 ㉗）も、体格に合わせて位置と高さが変わるため、タイプごとに作る（人型標準・タンク・カエル・動物の4セット）。

| タイプ | リグ | アニメーションの作り方 |
|---|---|---|
| ① ノーマル | Humanoid | 基準のセット（全てのアニメーションを作る） |
| ② 強化型 | Humanoid | ノーマルを流用し、再生速度を上げる（移動 0.85m/秒 ≒ 1.3倍）。攻撃は力強い版に差し替え（優先度 C） |
| ③ 反応型（クリーチャー型） | Humanoid（二足歩行のカエル型。長い脚を Humanoid の脚に割り当てる） | 体型と動きが大きく違うため、移動・攻撃・被ダメージ・体術を受ける動作を専用に作る。最初は「二足歩行のカエル」を作る（D-49）。舌で攻撃するタイプ（リッカー系）は将来の追加 |
| ④ タンク型 | Humanoid（大柄な体型） | 移動・攻撃・被ダメージ・体術を受ける動作を専用に作る（重い動き） |
| ⑤ 動物 | **Generic**（四足。Humanoid にできない） | 全て専用に作る（§5） |
| ⑥ 遠距離型 | Humanoid | ノーマルを流用し、毒を吐く攻撃・後退・適正距離を保つ移動を追加（§6）（D-50） |

### 1-2 移動方式
- 徘徊・追跡は、その場アニメーション ＋ NavMeshAgent による移動。
- ノックバック・ダウン・攻撃の踏み込み・体術を受ける動作・死亡は、RM（ルートモーション）または同期（プレイヤーとの位置合わせ）。
- 区分は 03 §1-4 と同じ。

### 1-3 移動速度と歩幅（06 の数値が基準）【暫定】

| アニメーション | 速度 | 1歩の間隔 | 1歩の距離 | 1周期（2歩） |
|---|---|---|---|---|
| Z_Walk（徘徊） | 0.40m/秒 | 1.0秒（06 の足音間隔） | 0.40m | 60f |
| Z_Chase（ノーマル） | 0.65m/秒 | 0.8秒 | 0.52m | 48f |
| Z_Chase（強化型） | 0.85m/秒 | ノーマルの Chase を約1.3倍速で再生 | ― | ― |
| Z_Chase_Tank | 0.45m/秒 | 1.2秒 | 0.54m | 72f |
| Z_Walk_Ranged | 0.50m/秒 | ノーマルの Chase を約0.77倍速で再生 | ― | ― |

- 06 の速度が調整で変わったら、まず再生速度で合わせる。再生速度が 0.7〜1.5倍の範囲を超えたら、アニメーションを作り直す。

### 1-4 群れで同じ動きに見せない工夫
- 複数体が同時に覚醒・徘徊するため、同じアニメーションが揃って見えないようにする。
  - ループの開始位置をランダムにずらす。
  - 再生速度を個体ごとに ±10% ずらす。
  - Humanoid の左右反転（Mirror）をランダムに使う。
  - 起き上がり・Idle・徘徊は2〜3種類を用意し、ランダムに選ぶ（優先度 B）。

### 1-5 攻撃の向きと踏み込み（D-47・D-48）
- 攻撃射程に入ったら、攻撃モーション（攻撃準備 → 踏み込み＋引っ掻き）を始める。
- 向き：攻撃準備の前半は、ゾンビがプレイヤーの方へ体を向け続ける。後半（最後の約1秒）は向きを固定する。固定後に横へ避ければ、攻撃を外せる。
- 攻撃は常に「ゾンビの正面」へ振る。8方向は「命中判定の瞬間に、プレイヤーがゾンビから見てどの方向にいるか」を判定する区分として使う（攻撃ごとに、命中する方向を指定する。引っ掻きは前・左前・右前など）。
- 踏み込み：腕の届く距離は約0.8m のため、攻撃動作に踏み込みを入れる。
  - アニメーションは踏み込み約2m で作り、ルートモーションの移動量をスクリプトで伸縮する。
  - 伸縮後の踏み込み距離 ＝ 踏み込みを始めた時点のプレイヤーとの距離 − 0.8m（ただし「攻撃射程 − 0.8m」を上限とする）。プレイヤーが既に近い場合は、ほとんど踏み込まずに引っ掻く。
  - 射程がタイプで違うため（タンク 1.5m、カエル 4.5m）、踏み込みの上限もタイプで変わる。カエルは4.5m を跳んで飛びかかる動きにする。

## 2. 状態の流れ

```
Sleep（倒れている）
  └ 感知 → 起き上がり（Sleep から）→ Half Awake（ゆらゆら歩く）
                                        └ 明確に感知 → Alert
Patrol（徘徊・未感知時の行動）─ 感知 → Alert
Alert ─ 追跡すると判断 → Chase
Chase ─ 攻撃射程 → Attack準備 → 通常攻撃 → 攻撃後（クールタイム）─┬ 射程内 → Attack準備
      │                                                           └ 射程外 → Chase
      ├ 0.60m 以内 → 掴み ─┬ 成功 → 噛みつき（プレイヤーは約2秒抵抗できる）→ 攻撃後
      │                     └ 失敗（空振り）→ 攻撃後
      └ 見失う → Lost → Patrol / 所定の位置へ戻る

（どの状態からでも）
被ダメージ → 部位怯み・体勢崩し（体術の受付）→ 体術を受ける／受付時間切れで元の状態へ
          → ノックバック → ダウン → ダウンからの起き上がり → Chase
          → 死亡 / Headshot Death
```

## 4. 各アニメーションの仕様（人型）

### ① Sleep / 倒れている
- 種類：睡眠・倒れている。ループする、動きは非常に小さい、呼吸の動きあり。
- 動作：ほとんど動かず、感染者が眠っているような状態。わずかに体が動く程度。視線は基本的に動かさない。
- 仰向けとうつ伏せの2種類を用意し、②の起き上がりと対応させる。
- プレイヤーを感知していない間：その場で待機する。感知したら：起き上がり（②）へ移る。

### ② 起き上がり（Sleep から）
- 種類：起き上がり。ループしない、動きは大きい。ゆっくり立ち上がる。
- 起き上がり中は攻撃も移動もできない。
- 完了したら：Half Awake（③）へ移る。
- 複数体が同時に覚醒するため、2〜3種類を用意し、開始のタイミングを個体ごとにずらす（§1-4）。
- ダウン（⑭）からの起き上がりには、別のアニメーション ⑭-2 を使う。

### ③ Half Awake / ゆらゆら
- 種類：半覚醒。ループする、動きは小〜中。
- 動作：体を起こした状態で、左右にゆらゆら揺れる。頭や体を不規則に動かす。
- 06 で「ゆらゆら歩く・ふらつく」と定義されたため、その場で揺れる Z_HalfAwake と、ふらつきながら歩く Z_HalfAwake_Walk の2本にする。
- 視線：周囲を不規則に見る。攻撃はしない。
- プレイヤーを明確に感知したら：Alert（⑥）へ移る。

### ④ Idle
- 種類：待機。ループする、動きは小さい。
- 姿勢：ゾンビ特有の不自然な立ち姿。
- 動作：体をわずかに揺らし、頭や腕を不規則に動かし、周囲を確認するような動きをする。
- 未感知の間は完全に静止させない（06 §9）。Idle の途中で ㉑〜㉔ の行動をランダムに挟む。
- プレイヤーを感知したら：Alert へ移る。

### ⑤ Walk（徘徊）
- 種類：歩行。ループする、動きは中、速度 0.40m/秒（全タイプ共通）。
- 姿勢：ゾンビ特有の前傾した不安定な姿勢。体を揺らし、不安定な足取りで歩く。腕や頭を不規則に動かす。
- 足音：接地のフレームに Footstep イベントを入れる（間隔 1.0秒）。足音はプレイヤーがゾンビの存在や種類を推測する手がかりになる。
- Alert 中の移動にもこのアニメーションを使う。

### ⑥ Alert
- 種類：警戒。ループする、動きは中。
- 動作：プレイヤーのいる方向を確認し、周囲を見回し、体をプレイヤーの方向へ向ける。
- 大きく向きを変えるときは Z_Turn_L90 / R90 / 180 を使う（優先度 B。それまではスクリプトの回転で代用）。
- 追跡すると判断したら：Chase へ移る。

### ⑦ Chase
- 種類：追跡。ループする、動きは中〜大、速度はタイプごと（§1-3）。
- 姿勢：プレイヤーを追うための前傾姿勢。
- 攻撃射程に入ったら：Attack準備（⑧）へ移る。0.60m 以内に入ったら：掴み（⑪）へ移る。
- 優先順位（D-46）：攻撃準備中は掴みに割り込まず、そのまま引っ掻く。それ以外の状態で 0.60m 以内に入ったら、掴みを優先する。
- 見失ったら：Lost（⑳）へ移る。

### ⑧ Attack準備
- 種類：攻撃準備。予備動作（Start）と溜めのループ（Loop）に分けて、準備時間3秒に合わせる。
- 動作：体を攻撃方向へ向け、腕を引くなどの予備動作を行う。**プレイヤーが攻撃を予測できる、分かりやすいポーズにする**。
- 向き：前半はプレイヤーの方へ向き続け、最後の約1秒は固定する（§1-5）。
- 準備中は移動できない。ダメージ判定は無い。
- プレイヤーが距離を取っても準備時間はリセットせず、そのまま攻撃へ移る。

### ⑨ 通常攻撃（踏み込み＋引っ掻き）
- 種類：通常攻撃。ループしない、動きは大きい、移動方式は RM。
- 動作：踏み込みながら腕を振って引っ掻く。踏み込みの距離は、プレイヤーとの距離に合わせてスクリプトで伸縮する（§1-5）。
- 攻撃判定：Hit_Start / Hit_End イベントの間。8方向の区分で判定する（§1-5）。
- 命中・空振りに関係なく、攻撃後（⑩）へ移る。

### ⑩ 攻撃後（クールタイム）
- 攻撃後の姿勢から通常の姿勢へ戻る（Z_Attack_Recover）。
- クールタイム（ノーマル3秒、強化型とタンク型は5秒）の間は、構え直したり、周囲をうろちょろ動いたりする（Z_Cooldown_Shuffle：小さく左右へ歩く）。必要に応じて、体をプレイヤーの方向へ向ける。
- クールタイム後：プレイヤーが射程内なら Attack準備へ、射程外なら Chase へ移る。

### ⑪ 掴み・噛みつき
- 発動条件：プレイヤーが 0.60m 以内にいる。
- プレイヤーの「掴まれ」（03 ㉕）と同期して再生する。

| 段階 | 時間【暫定】 | ゾンビ | プレイヤー |
|---|---|---|---|
| 掴みかかる | 約0.5秒 | Z_Grab_Start | ― |
| 掴みの失敗（回避された） | ― | Z_Grab_Miss（空振り）→ 攻撃後へ | ― |
| 掴みの成功（抵抗の受付） | 約2秒（D-37） | Z_Bite_Hold | Grab_Front_Start → Grab_Struggle_Loop |
| 抵抗に失敗 | 約1.0秒 | Z_Bite_Success（噛みつく） | Grab_Bitten |
| 抵抗に成功 | 約1.0秒 | Z_Bite_Pushed（吹き飛ばされる → ダウンへ） | Grab_Escape |

- 06 の「噛みつき動作時間 約1.5秒」は、掴みかかり（約0.5秒）と噛みつき（約1.0秒）の合計とし、抵抗の受付時間（約2秒）は別に数える。
- 噛みつきの後は、攻撃後クールタイム（⑩）を適用する。
- 06 で「掴みに成功すると噛みつく」とあるため、掴みが失敗する場合（Z_Grab_Miss）を追加した。

### ⑫ 被ダメージ
- ループしない、動きは小〜中。攻撃を受けた方向に応じて一瞬怯む（前後左右の4方向）。
- 被ダメージの後：通常状態へ戻る。ノックバック・ダウン・体勢崩しが発生する場合は、それぞれへ移る。

### ⑬ ノックバック
- ループしない、動きは大きい、移動方式は RM、硬直あり。
- 方向：攻撃の力の向き（攻撃者から離れる方向）に押し戻され、バランスを崩す。
- 移動距離：武器のノックバック性能 ×（1 − ゾンビのノックバック耐性）で決め、ルートモーションの移動量をスクリプトで伸縮する。
  - 補正後の距離が 0.3m 未満になった場合は、ノックバックではなく⑫の被ダメージを再生する【暫定】（タンク型の耐性90%で、小さすぎるノックバックが不自然に見えるのを防ぐため）。
- 終了後：通常状態へ戻る。ダウンや体勢崩しが発生する場合は、それぞれへ移る。

### ⑭ ダウン
- ループしない、動きは大きい。前から攻撃されると仰向け、後ろから攻撃されるとうつ伏せに倒れる。倒れている間は Loop を再生する。
- ダウン中は通常の行動・攻撃・移動ができない。踏みつけ（体術）を受け付ける。
- 一定時間後：ダウンからの起き上がり（⑭-2）へ移る。

### ⑭-2 ダウンからの起き上がり
- ②（Sleep から）よりも速く起き上がる。仰向け・うつ伏せの2種類。完了したら Chase へ戻る。

### ⑮ 死亡
- ループしない、動きは大きい。攻撃された方向に応じて前後の2種類。
- 死亡後は行動・攻撃・移動をせず、起き上がらない。復活しない。
- 他のゾンビを連鎖覚醒させる場合があるため（06 §3）、死亡時に DeathNoise イベントを出す。
- ダウン中に死亡した場合は Z_Death_Down を使う。倒れた後にラグドールへ切り替えるかは、制作時に検討する。

### ⑯ 部位怯み・体勢崩し
- 部位ごとの怯み値が一定に達すると、体勢崩し状態になる（04 §7）。部位に対応した姿勢で崩れ、体術の受付時間の間はその姿勢を続ける。

| 部位 | 崩れる姿勢 | 受け付ける体術 |
|---|---|---|
| 頭（非致死） | Z_Stagger_Head：膝をついて怯む | 回し蹴り |
| 肩 | Z_Stagger_Shoulder：上半身をのけぞらせて怯む | 体当たり |
| 腰 | Z_Stagger_Waist：うずくまって怯む | 前蹴り |
| 足 | Z_Stagger_Leg：ふらついて怯む | 足払い |
| 転倒 | ⑭ ダウン：倒れて怯む | 踏みつけ |

- 受付時間が過ぎたら、元の状態へ戻る。

### ⑰ 体術を受ける
- プレイヤーの体術（03 ㉗）と同期して再生する。移動方式は同期。

| 体術 | ゾンビのクリップ | 結果（提案） |
|---|---|---|
| 回し蹴り | Z_Takedown_Recv_Head | 転倒（ダウン） |
| 体当たり | Z_Takedown_Recv_Shoulder | ノックバック |
| 前蹴り | Z_Takedown_Recv_Waist | ノックバック |
| 足払い | Z_Takedown_Recv_Leg | 転倒（ダウン） |
| 踏みつけ | Z_Takedown_Recv_Stomp | 大ダメージ（死亡することもある） |

- 体術の後は、効果に応じた状態へ移り、終わったらゾンビの AI に戻る。

### ⑱ Headshot Death
- 頭部への致死ダメージで、他の死亡より優先して再生する。頭部が体から分離し、頭部が無い状態で倒れる（Z_Death_Headshot：膝から崩れ落ちる）。
- モデルの準備（全タイプ共通）：
  - 頭部を別のメッシュ（または別のマテリアルの範囲）にし、表示と非表示を切り替えられるようにする。
  - 首の断面を塞ぐメッシュ（普段は非表示）を用意する。
  - 飛んでいく頭部は、物理演算で動く別のオブジェクトとして生成する。

### ⑲ 足の負傷による移動
- 足への攻撃で移動能力が下がっている間は、足を引きずる Z_Walk_Limp / Z_Chase_Limp を使う。

### ⑳ Lost（見失う）
- 最後に感知した位置へ歩いて行き、周辺を見回す（Z_Lost_Search）。一定時間後に徘徊または所定の位置へ戻る。

### ㉑〜㉔ 未感知時の行動（06 §9）
- 「気づいたらいる」恐怖を作るため、未感知の間もゾンビに行動させる。
- 咀嚼（㉑）：しゃがんで死体を食べるループ。気付いたら立ち上がる（Z_Eat_StandUp）。咀嚼音を Sound イベントで出す。
- 壁を叩く（㉒）：音を出すので、プレイヤーが遮蔽物越しに存在に気付ける。
- ドアにぶつかる・他のゾンビとぶつかる（㉓）：短い反応。
- 立ち止まって見回す（㉔）。

## 5. 動物ゾンビ（Generic リグ・全て専用）

ゲーム仕様書 §4.16 では、動物ゾンビは犬・鳥・虫の3種類。骨格も動きもまったく違うため、別々に作る。

| 種類 | リグ | 特徴 | 優先度 |
|---|---|---|---|
| 犬 | 四足の Generic | 高速突進・噛みつき・高い移動性能。下の表のアニメーションを作る | B（最初に作る） |
| 鳥 | 飛行の Generic | 空中移動・空中急襲・視界外からの攻撃。飛行・滑空・急降下・着地などが必要 | C |
| 虫 | 小型。群れで動かすため、1体ずつの骨格アニメーションではなく、軽い仕組み（頂点アニメーションや簡単な骨格）にする | 小型・高速移動・刺突・群れ行動 | C |

- ナイフなどの近接攻撃で即死させられる（ゲーム仕様書 §4.16）。ナイフが当たったら、体術を使わずに死亡アニメーションを再生する。
- 以下の表は犬のアニメーション。

| クリップ | ループ | 移動方式 | 内容 |
|---|---|---|---|
| A_Sleep / A_WakeUp | する / しない | その場 | 伏せて眠る / 起き上がる |
| A_Idle | する | その場 | ― |
| A_Walk | する | その場 | 徘徊 0.40m/秒、移動 0.65m/秒 |
| A_Charge_Start / A_Charge_Loop | しない / する | その場 | 4m 以内で突進を始める。突進 2.0m/秒 |
| A_Charge_Bite | しない | RM | 突進しての噛みつき |
| A_Recover | しない | その場 | 攻撃後の大きな隙 |
| A_Hit / A_Knockback / A_Death / A_Death_Headshot | しない | その場 / RM | ― |

- 動物ゾンビも体勢崩しと体術の対象にする。体術は動物専用のセットを作る（D-49）。掴みはせず、突進しての噛みつきで攻撃する。
- 追加：A_Stagger（体勢崩し）、A_Takedown_Recv 一式。

## 6. 遠距離型ゾンビ（毒を吐く）（D-50）

| クリップ | 内容 |
|---|---|
| Z_Spit_Prepare | 毒を吐く準備（喉を膨らませるなど。特徴的な準備音を Sound イベントで出す） |
| Z_Spit_Attack | 毒を吐く（Spit_Release イベントで毒の弾を生成） |
| Z_Walk_Back / Z_Strafe_L / R | 後退と横移動。適正距離（6〜10m）を保つため、プレイヤーの方を向いたまま移動する |

- 毒は山なりに飛ぶ（D-58）。命中すると単発のダメージを与える。継続ダメージは無いため、プレイヤー側に毒状態のアニメーションは不要。
- Z_Spit_Attack は、山なりに飛ばすため顔を少し上に向けて吐く動きにする。
- 長い舌で攻撃するタイプは将来の追加とする。

## 6-2. 反応型ゾンビ（二足歩行のカエル）（D-49）

| クリップ | 内容 |
|---|---|
| F_Idle / F_Walk / F_Chase | 前かがみの二足歩行。追跡は跳ねるように移動する |
| F_Attack_Prepare / F_Attack_Leap | 身を屈めて溜める → 最大4.5m 跳んで飛びかかり、引っ掻く（RM を距離に合わせて伸縮） |
| F_Hit / F_Knockback / F_Down / F_GetUp / F_Death / F_Death_Headshot | カエル専用の被ダメージと死亡 |
| F_Stagger_Head / Shoulder / Waist / Leg | 体勢崩し（発動条件はゾンビと同じ） |
| F_Takedown_Recv 一式 | 体術を受ける動作（カエルの体格に合わせる） |

- 噛みつきは無い。
- 覚醒と反応が速いため、起き上がりと Alert は短く作る。足音は小さい（06 §10）。
