## 1. 共通方針

### 1-1 基本の考え方
- プレイヤーは常に何かの武器を持っている（D-20）。素手の状態は作らない。
- 武器の構え（Ready）を、その武器を持っているときの全ての動作の基準姿勢とする。武器を持っている間は、常に警戒態勢で動く。
- 下半身（移動）と上半身（武器の構え）を Animator Layer と Avatar Mask で分離する。
  - 移動アニメーションは武器ごとに作らない。上半身レイヤーが武器の構えを上書きする。
  - これにより「構えを維持したまま移動する」「移動しても武器の位置が崩れない」を仕組みとして実現する。
- 武器は「持ち方クラス」（04 §13）で管理する。構え・エイム・取り出し・収納・抱え込みはクラスごとに1本、射撃とリロードは武器ごとに作る。
- 全身アクション中の腕（D-21、04 §13-1）

  | 動作 | 拳銃・ナイフ | 長物・肩担ぎ・弓 |
  |---|---|---|
  | 回避（ステップ）、立ったままの被ダメージ | 構え（Ready）を維持する | 構え（Ready）を維持する |
  | 地面に伏せる・転がる・吹き飛ぶ動作（着地ローリング、ノックバック、ダウン、起き上がり、死亡、掴まれ） | 共通の腕（利き手に小型武器を握る） | 抱え込み（Carry）：利き手でグリップをしっかり握り、支える腕で武器を抱える |

  - 回避は転がらず、ステップで移動する。

### 1-2 ストレイフと体の向き（D-11、D-26）
- 全ての移動（歩き・しゃがみ移動・ダッシュ）はストレイフにする。キャラクターは常にカメラの向き（視点方向）を正面とし、入力方向へ移動する。
- **利き手の肩が後ろ、反対の肩が前**になる半身の構えで、前後左右と斜めの全方向へ移動する。ダッシュも同じ。

  | 部位 | 右利き | 左利き |
  |---|---|---|
  | 胸・肩 | 照準方向から右へ約30°開く（右肩が後ろ、左肩が前） | 左右が逆 |
  | 骨盤 | 照準方向から右へ約15°開く | 左右が逆 |
  | 足 | 左足がやや前寄り | 左右が逆 |

  角度は【暫定】。胸と骨盤の角度差（約15°）で、体幹のひねりを表現する。
- この半身の構えは、移動アニメーション（Base レイヤー）そのものに入れて作る。上半身レイヤーの Mask は腕だけなので、体幹の向きは Base 側で決まるため。
- 立ち止まったままカメラを回したときは、上半身が背骨の照準で ±60° まで追従する。それを超えたら、その場旋回（㉓）で体の向きを直す。

### 1-3 利き手への対応（D-26）
- 左利きは右利きの動作を左右反転したものにする。
- 実装：Unity Humanoid のアニメーション反転（Animator のステートの Mirror を、パラメータで切り替える）を使い、アニメーションを左右で2本ずつ作らない。
- 反転で対応できないもの：
  - Weapon_R / Weapon_L などの Humanoid 以外のボーンのアニメーションは反転されない。左利きのときは、武器の持ち手とソケットをスクリプトで入れ替える。
  - 左手 IK は右手 IK に入れ替える。
  - 収納位置（ホルスター・鞘・ポーチ）は左右を入れ替える（02 §8-4）。
- 利き手はキャラクターごとに固定で管理する（D-41）。キャラクターの設定データに利き手を持たせ、Animator の Mirror パラメータを初期化時に設定する。

### 1-4 移動方式（ルートモーション）の区分

| 区分 | 内容 | Unity の Bake Into Pose 設定 |
|---|---|---|
| その場 | 移動はスクリプトで行う | 回転・Y・XZ を全て Bake |
| RM | ルートモーションで移動する | 回転・Y は Bake、XZ は Bake しない |
| RM-回転 | 回転だけをルートモーションで行う | Y・XZ は Bake、回転は Bake しない |
| 同期 | 位置をスクリプトでゾンビに合わせる | その場と同じ |

- Unity 側では、ステートに「RootMotion」タグを付ける。タグがあるステートでは OnAnimatorMove で deltaPosition を CharacterController に渡し、それ以外はスクリプトの速度で移動する。

### 1-5 移動速度と1周期の長さ（ゲーム仕様書 §18.1 に合わせた）【暫定】

アニメーションは下の速度に合わせて作る（合わないと足が滑る）。フレームレートは 30fps。

| アニメーション | ゲーム仕様書の速度 | 1周期（2歩） | 1歩の距離 |
|---|---|---|---|
| Crouch_Walk（忍び歩き） | 1.2 m/s | 30f（1.0秒） | 0.60m |
| Walk（通常歩行） | 3.0 m/s | 23f（約0.77秒） | 約1.15m |
| Run（ダッシュ） | 4.5 m/s | 21f（0.7秒） | 約1.58m |
| Tired_Walk（疲労状態の移動） | 1.2 m/s（D-62） | 30f（1.0秒） | 0.60m |
| エイム中の移動 | 通常歩行の0.85倍 | 再生速度も0.85倍 | ― |
| 武器の重量による補正 | 04 §13-2 の倍率を掛ける | 再生速度も同じ倍率 | ― |

- 速度はゲームの操作感を優先した値で、現実より速い（D-61）。現実の人の歩きは約1.3m/秒のため、3.0m/秒で足が滑らないよう、通常歩行は**歩幅を大きくとった警戒した速歩き（小走り寄り）**として作る。上半身は構えを保ち、上下の揺れを抑えて「歩いている」印象を残す。
- 前後左右の速度はゲーム仕様書では区別していないため、同じ速度で作る。後退や横移動を遅くする場合は、ゲーム側の値を決めてから再生速度で合わせる。
- 斜めの速度は、Blend Tree で隣り合う2方向の間を補間した値になる。

### 1-6 キャラクター性（華奢・任務経験が浅い）
- 常に少し肩に力が入っている。視線をこまめに動かす。
- 被弾の反応・ノックバックは、熟練兵より大きめにする。重い武器ほど振り回されている感じを出す。
- 照準は全キャラクター共通で固定し、経験の浅さで揺らすことはしない（D-56）。
- 息切れしやすい。
- 体術は、派手な格闘技ではなく、必死さが出る動きにする。
- ただし、入力への反応とキャンセルのタイミングは演技のために遅くしない。

### 1-7 キャンセルの共通ルール
- 「回避でキャンセル可能」なアニメーションには、キャンセル受付の開始をアニメーションイベントで入れる（§9）。
- 回避でキャンセルしたときは、そのアクションの効果は発生しない（例：リロードで弾が補充されない、アイテムが消費されない）。

### 1-8 キャラクター別の差分（D-14、D-23）
- 同じ Humanoid の構造なので、ほとんどのアニメーションは男女で共用できる。キャラクター固有の部分だけを Animator Override Controller で差し替える。

| 項目 | 女性（本キャラクター） | 男性（将来作成） |
|---|---|---|
| 拳銃の構え | 銃口を下に向ける（ローレディ） | 銃口を上に向ける（ハイレディ） |
| 武器の大きさ | 女性用の武器プレハブ（小さめ） | 男性用の武器プレハブ |

## 2. 武器の状態

| 状態 | 上半身の構え | 収納位置（右利き） |
|---|---|---|
| H 拳銃（無限ピストル） | H_Ready：両手持ちで銃口を下に向ける | 右太もものホルスター |
| H 拳銃（マグナム・リボルバー） | H_Ready（無限ピストルと共用） | 腰の後ろのホルスター |
| K ナイフ | K_Ready：利き手で順手に握って前に出し、反対の手で防御の構え | 胸ハーネスの左側 |
| R 長物 | R_Ready：銃口を下げて胸の前で保持 | 背中 |
| L 肩担ぎ | L_Ready：腰の高さで抱える | 背中 |
| B 弓 | B_Ready：弓を下げて持ち、利き手は矢筒の近く | 背中 |

- ナイフは独立した武器。他の武器と同時には使えない（D-15）。
- 手榴弾は常時装備。専用ボタンで、今持っている武器のまま投げる（⑳）。
- アイテム使用・投擲・トラップ設置の間は、利き手の武器を反対の手へ持ち替える。反対の手のポーズは共通とし、武器の付け位置を持ち方クラスごとに調整する（長物は銃口を下にしてぶら下げる）。

## 3. Animator の構成（案）

| レイヤー | Avatar Mask | 合成方法 | 内容 |
|---|---|---|---|
| 0 Base | なし（全身） | ― | 移動（立ち・しゃがみ・ダッシュ）、旋回、ジャンプ・落下・着地、回避、被ダメージ、ノックバック、ダウン、起き上がり、死亡、掴まれ、ナイフ攻撃、体術、押しのけ、拾う、トラップ設置 |
| 1 UpperArms | 両腕・両手 | Override | 武器の構え（Ready）、地面に伏せる動作中の抱え込み（Carry） |
| 2 UpperBody | 体幹・頭・両腕・両手 | Override | エイム、腰だめ撃ち、リロード、武器の取り出しと収納、アイテム使用、投擲、インタラクト |
| 3 Additive | 体幹・頭・両腕 | Additive | 射撃の反動、軽い被弾、深呼吸、息切れ、負傷 |

- 回避と、立ったままの被ダメージの間：レイヤー1（Ready）は有効のまま、レイヤー2のウェイトを0にする。
- 地面に伏せる動作の間：レイヤー2のウェイトを0にする。レイヤー1は、拳銃・ナイフでは0（Base の共通の腕を使う）、長物・肩担ぎ・弓では Carry に切り替えてウェイトを1にする。
- 武器ごとの差し替えは Animator Override Controller で行う（04 §13-3）。
- 左利きのときは、全てのステートの Mirror を有効にする（§1-3）。
- Unity の Animation Rigging で制御するもの：

| 制御 | 使う場面 | 使わない場面（ウェイト0） |
|---|---|---|
| 反対の手の IK（武器に追従させる） | 両手持ちの武器の Ready / Aim / 射撃 | リロード、取り出し・収納、アイテム、投擲、地面に伏せる動作 |
| 背骨の照準（左右のみ） | 立ち止まってカメラを回したとき（±60° まで） | 地面に伏せる動作、体術、掴まれ |
| 上下の照準（腕と頭） | エイム中・腰だめ撃ち中。背骨は動かさない（D-56） | 同上 |
| 頭の視線 | 常時（カメラの注視点を見る） | 地面に伏せる動作、体術、掴まれ |

## 6. 各アニメーションの仕様

### ① Idle（待機）
- 種類：固定、ループする、動きは小さい、移動方式はその場、長さ 120f（4秒）【暫定】
- 姿勢：半身の構え（§1-2）。少し肩に力が入り、重心はやや前寄り。常に警戒態勢。
- 呼吸：Idle のループには通常の呼吸だけを入れる。
- 深呼吸（D-12）：頻繁にはせず、一定の間隔で1回ずつ入れる。
  - Breath_Deep（加算）を、止まっている状態（Idle / Crouch_Idle）が続いている間、**8秒ごと**【暫定】にスクリプトで再生する。
  - 加算方式なので、どの武器を構えていても、しゃがんでいても同じ1本で使える。
- 見回し：Idle のループには入れない。入力が無い状態が 8〜15 秒続いたら、Idle_Break_Look をランダムに再生する（頭の IK とぶつからないようにするため）。
- 武器の構え：上半身レイヤーで Ready を上書きする。
- アイテム使用への切り替え：⑲を参照。

### ②〜⑤ Walk（前・後・左・右 → 後に8方向）
- 種類：歩行、ループする、動きは小〜中、移動方式はその場。
- ストレイフ（§1-2）。常にカメラ正面を向き、半身の構えのまま入力方向へ移動する。
- 速度と1周期：§1-5 を参照。
- 視線：カメラ正面（頭の視線 IK）。
- 腕：上半身レイヤーで武器の構えを維持する。
- 足音：接地のフレームに Footstep イベントを入れる（足音はゾンビの感知にも使う。通常歩行・忍び歩き・ダッシュで音の大きさを変える）。
- 斜め移動：4方向版では Blend Tree（2D Freeform Directional）で補間する。8方向化は 01 §2-5 の条件を満たしてから行う。

### ⑥ Run / Dash（D-11）
- ダッシュ中の武器（D-63）
  - ナイフ：ダッシュ中でも振れる。走りながら斬る K_Dash_Slash（上半身レイヤー。下半身はダッシュを続ける。横斬り1本を作り、左右反転で2方向）を使う。
  - 銃・アイテム・手榴弾：ダッシュ中は使えず、抱えたまま走る。照準や撃つボタンを入力するとダッシュを解除する（アイテムと手榴弾の入力も同じ扱い【暫定】）。
- 種類：走り、ループする、動きは大きい、移動方式はその場。
- ダッシュもストレイフ。前後左右の4方向で作り、8方向化で斜めの4本を追加する。半身の構えを保ったまま走る。
- 速度：§1-5（後ろへのダッシュは遅くする）。
- 姿勢：前傾。武器は抱えたまま走る。拳銃とナイフは共通の腕（利き手に小型武器を握る）、長物・肩担ぎ・弓は Carry（利き手でグリップを握り、支える腕で抱える）。
- ダッシュ中は照準・射撃・リロードができない。照準か射撃を入力するとダッシュを解除し、Walk へ減速してその操作を行う。
- スタミナ：ダッシュ中は毎秒20消費する（満タンから約5秒で0）。スタミナが0になったら疲労状態（㉖）へ移る。
- 激しい呼吸：ダッシュを始めてから2.0秒後に「激しい呼吸」（ゾンビ側では呼吸音。06 §6）が始まる。基本の継続時間は5.0秒、スタミナ70以上で解除。激しい呼吸はサウンドだけで表現し、専用のアニメーションは作らない（D-67）。呼吸のサウンドの開始と停止を、呼吸音（ゾンビの感知）の発生と解除のタイミングに合わせる。

### ⑦ 回避（ステップ）
- 種類：回避ステップ（転がらない）、ループしない、動きは大きい、移動方式は RM。
- 長さ：移動 18f（0.6秒）＋ 回避後の硬直 6f（0.2秒。ゲーム仕様書 §18.1）＝ 24f。移動距離 約1.8m【暫定】
- 方向：Dodge_F / B / L / R を 2D Blend Tree で入力方向に合わせる（斜めも補間）。8方向化で斜めの4本を追加する。
- 無敵時間：ゲームシステム側で設定する。アニメーションには Invincible_Start / End イベントを入れる。
- 武器：構え（Ready）を維持する（全クラス共通）。
- 回避の後：Idle または移動へ戻る。しゃがみ中に回避したら、回避の後にしゃがみへ戻る。
- スタミナを1回15消費する。残りが15未満のときは回避できない（アニメーションは再生しない）。

### ⑧ ジャンプ【要確認 Q-14】
- Jump_Start（踏み切り）と Fall_Loop（⑨）に分ける。滞空時間が毎回変わるため。
- Jump_Start：ループしない、長さ 8f、移動方式はその場（上昇は物理で行う）。体を沈めて踏み切る。
- 武器：構えを維持する。
- ジャンプ中の射撃（D-39）：腰だめ撃ちはできる。照準（エイム）はできない。エイム中にジャンプを入力したら、エイムを解除してジャンプする。

### ⑨ 落下
- 種類：落下、ループする、動きは中、移動方式はその場、長さ 30f。
- 足：地面を探すような自然な動き。武器の構えは維持する。
- 地面に触れたら、落下した高さに応じて⑩の種類を決める。

### ⑩ 着地

| 落下の高さ【暫定】 | 移動入力なし | 移動入力あり |
|---|---|---|
| 1.0m 未満 | Land_Light（6f。すぐに移動できる） | Land_Light |
| 1.0〜2.5m | Land_Heavy（18f。短い硬直） | Land_Roll（RM、27f） |
| 2.5m 以上 | Land_Heavy ＋ 落下ダメージ | Land_Heavy ＋ 落下ダメージ |

- Land_Roll の間は、拳銃・ナイフは共通の腕、長物などは Carry で武器を抱える。
- 着地の後：移動入力があれば移動へ、無ければ Idle へ戻る。武器は構えへ戻る。

### ⑪ 被ダメージ
- 軽い被弾：Hit_Light を加算で重ねる。移動は止めない。
- 中程度の被弾：Hit_F / B / L / R（攻撃された方向へ体が反応）。ループしない、長さ 15f、短い硬直あり、移動方式はその場。
- 武器：構え（Ready）を維持する（立ったままのため）。
- 被ダメージの後：通常状態へ戻る。ノックバック・ダウンが発生する場合は、それぞれへ移る。
- しゃがみ中：加算の反応だけにする。ノックバック・ダウンが発生したら、自動で立ち姿勢に戻す。

### ⑫ ノックバック
- 方向の定義：攻撃の力の向き（攻撃者から離れる方向）に体が飛ばされる。
- 前から攻撃された場合：Knockback_Back。後ろから攻撃された場合：Knockback_Front。
- ループしない、動きは大きい、移動方式は RM、長さ 24f。移動距離は 0.5〜1.0m（ゲーム仕様書 §18.1）。アニメーションは 1.0m で作り、スクリプトで縮める。
- 距離：攻撃ごとの飛ばし距離に合わせるため、スクリプトでルートモーションの移動量に倍率をかける。
- 武器：拳銃・ナイフは共通の腕、長物などは Carry。
- 硬直あり。終了後は通常状態へ戻る。ダウンが発生する場合はダウンへ移る。

### ⑬ ダウン
- 倒れる動作（Start）と、倒れている間のループ（Loop）に分ける。倒れている時間が可変になるため。
- 前から攻撃された場合：Down_Back（仰向け）。後ろから攻撃された場合：Down_Front（うつ伏せ）。
- Start：ループしない、RM、長さ 24f。Loop：ループする、その場。
- 武器：拳銃・ナイフは共通の腕、長物などは Carry。
- ダウン中は通常の操作ができない。ダウンの後は起き上がり（⑭）へ移る。

### ⑭ 起き上がり
- 仰向けからは GetUp_Back、うつ伏せからは GetUp_Front。
- ループしない、動きは中〜大、移動方式は RM（わずかに移動）、長さ 36f。
- 武器：拳銃・ナイフは共通の腕、長物などは Carry。立ち上がったら構えへ戻す。
- 起き上がり中は通常の操作ができない。最後の 6f だけ回避を受け付ける【暫定】。

### ⑮ ナイフ攻撃（斬る方向を指定）（D-24）
- ナイフは独立した武器。他の武器と同時には使えない。
- 操作：攻撃ボタンを押しながら、マウスやスティックで**斬る方向**を指定し、攻撃入力で確定する。
  1. 攻撃ボタンを押している間：K_Direction_Hold（ナイフを構え、指定した方向へ刃の向きを変える）。この間も移動できる（上半身レイヤー）。
  2. 攻撃入力で確定：指定した方向の斬撃を再生する。

  | 指定方向 | クリップ | 狙いやすい部位 |
  |---|---|---|
  | 上 | K_Slash_Down（振り下ろし） | 頭・肩 |
  | 下 | K_Slash_Up（斬り上げ） | 足 |
  | 左 / 右 | K_Slash_Left / Right（横斬り） | 腰 |
  | 指定なし | K_Thrust（突き） | 胴体 |

  方向と部位を対応させ、04 の部位怯み・体勢崩し・体術のシステムにナイフを組み込む。
- 斬撃：ループしない、動きは中、移動方式は RM（小さく踏み込む）、長さは 15〜21f。攻撃中は移動できない。
- 連続攻撃：斬撃の後半にある受付時間（Combo_Open / Close）の間に次の方向を指定して入力すると、続けて斬る。
- 回避でキャンセルできる。攻撃判定は Hit_Start / Hit_End イベントで区切る。
- 攻撃の後：K_Ready（ナイフの構え）へ戻る。

### ⑯ 射撃（Aim の作り方は §8）
- 射撃には「エイム中の射撃」と「腰だめ撃ち」の2種類がある（D-38）。
  - エイム：ズームして照準を合わせて狙う状態。
  - 腰だめ撃ち：エイムしていない、武器を構えているだけの状態で撃つ。レティクルが大きく広がり、弾のばらつきが大きくなる。

| 種類 | 単発の武器 | 連射の武器 |
|---|---|---|
| エイム中の射撃 | Aim のポーズに Fire（加算）を重ねる | Aim のポーズに連射用の Fire（加算ループ）を重ねる |
| 腰だめ撃ち | 構え → 腰だめ撃ち → 構え、を1発ごとに繰り返す（HipFire） | 撃っている間は、腰だめ撃ちのアニメーションを続ける（HipFire_Loop） |

- 単発の腰だめ撃ちは、次の入力が短い間隔（【暫定】0.4秒以内）で続く間は構えへ戻らず、撃つ姿勢のまま次の発射へつなぐ。連打のたびに構えと撃つ姿勢を往復すると、腕が上下に揺れ続けて見えるため。
- 射撃中も移動できる（下半身はストレイフ）。回避でキャンセルできる。
- 無限ピストルは単発で、撃つボタンの連打で連射する（最大 約3発/秒）。
- 弾は銃口から、射撃を入力した瞬間の照準点へ向けて飛ぶ（D-25、04 §12）。
- 武器ごとの射撃アニメーションは §5 を参照。

### ⑰ リロード
- ループしない、動きは中、レイヤーは UpperBody。
- 長さ：アニメーションは武器ごとに1本作り、**再生速度で武器のリロード時間に合わせる**（04 §13-4）。リロード時間はタイプとレベルで変わるため。
- リロード中も移動できる。攻撃はできない。
- 回避でキャンセルできる。Mag_In イベントより前にキャンセルした場合、弾は補充されない。
  - 1発ずつ込める武器（ショットガン）は、込めた分だけ装填される。
- 反対の手の IK は OFF にする（反対の手がマガジンを取りに行くため）。マガジンはベルトの前側ポーチから取る。
- イベント：Mag_Out → Mag_In（弾数を反映）→ Reload_End。
- リロードの後：装備している武器の構えへ戻る。

### ⑱ 武器切替（収納＋取り出し）
- 「収納（Holster）」と「取り出し（Draw）」の2本に分け、持ち方クラスごとに作る。
  - 例：ピストル → アサルトライフル ＝ H_Holster ＋ R_Draw（背中から取り出す）。
  - マグナム・リボルバーは腰の後ろから取り出すため、H_Draw_Back / H_Holster_Back を追加する（優先度 C）。
- 長さ：Draw 12〜15f、Holster 10〜12f【暫定】。背中の武器と重いクラスは長くする。レイヤーは UpperBody。
- 武器切替中は攻撃できない。移動はできる。
- 回避でキャンセルできる。キャンセルした時点で手に持っている武器を装備状態とする。
- イベント：Attach_Hand（武器を手に付け替える）/ Attach_Holster（武器を収納位置に付け替える）。

### ⑲ アイテム使用
- ループしない、動きは中、レイヤーは UpperBody、長さ 60f（2.0秒）。
- 流れ：
  1. 利き手の武器を反対の手へ持ち替える（Swap_To_Off）
  2. 利き手で太もものポーチからアイテムを取り出す（Item_Spawn）
  3. アイテムを使う（Item_Effect＝効果の発動とアイテムの消費）
  4. 武器を利き手へ戻す（Swap_To_Main）
- 使用中も移動できる。攻撃はできない。
- キャンセル条件（ゲーム仕様書 §16）：回避の入力（そのまま回避する）／ダメージを受ける／選択しているアイテムを変える／トラップを取り出す。Item_Effect より前にキャンセルした場合、効果は発生せず、アイテムも消費されない。
- 動作は2種類に分ける（D-65）。長さはどちらも60f（2.0秒）。
  - Item_Use_Herb：薬草（即時回復・継続回復）。葉を口に入れて噛む。
  - Item_Use_Drink：調合薬とシールドポーション。容器から飲む。
- 使用の後：使う前に装備していた武器の構えへ戻る。
- 回復アイテムで共通に使う。トラップは㉝で別に扱う（D-13）。

### ⑳ 手榴弾・投擲
- 常時装備。専用ボタンで、今持っている武器のまま投げる（武器を切り替えない）。
- Throw_Hold（構えて狙う。ループ）と Throw_Release（投げる。約18f）に分ける。
- 流れ：武器を反対の手へ持ち替える → ポーチから手榴弾を取る → 構える（Hold。固定レティクルと軌道を表示）→ 投げる（Release イベントで手榴弾を生成）→ 元の姿勢へ戻る。
- 構えている間もストレイフで歩ける。
- 投擲中は攻撃できない。回避でキャンセルできる（Release より前なら、手榴弾は消費されない）。
- 投擲の後：投擲前に装備していた武器の構えへ戻る。

### ㉑ しゃがみ Idle
- 種類：固定、ループする、動きは小さい、移動方式はその場、長さ 120f。
- 姿勢：膝を深く曲げ、半身の構えのまま上半身を起こして警戒する。
- 武器：上半身レイヤーで武器の構えを上書きする（立ちと同じ仕組み）。
- 深呼吸（Breath_Deep）も立ちと同じ間隔で重ねる。
- しゃがみの切り替え：ボタンで切り替える。当面は 0.25秒のブレンドで遷移する。
- しゃがみ中にできないこと：ダッシュとジャンプ。入力すると自動で立ち上がる。

### ㉒ しゃがみ移動（Crouch_Walk）＝ 忍び歩き（D-51）
- しゃがんで移動することを「忍び歩き」とする。足音は最も小さい「忍び歩き」の音（06 §5）。
- 前・後・左・右の4方向で開始し、立ちの Walk と同じ条件で8方向化する。常にストレイフ、半身の構え。
- 上半身：武器の構えを維持する。射撃・リロード・アイテム使用もできる（上半身レイヤーのため）。

### ㉓ その場旋回
- 常にストレイフのため、止まったままカメラを回す場面が多い。そのため優先度 A とする。
- 上半身は背骨の照準で ±60° まで追従する。それを超えたら Turn_L90 / R90 で足を踏み替えて向きを直す。
- 自作するまでは、スクリプトの回転で代用する。

### ㉔ 死亡
- 前から攻撃された場合：Death_Back。後ろから攻撃された場合：Death_Front。
- ループしない、移動方式は RM、長さ 45〜60f。最後の姿勢のまま止める。
- 武器は途中で手から落とす（Drop_Weapon イベント）。落とすまでは、拳銃・ナイフは共通の腕、長物などは Carry。

### ㉕ 掴まれ（D-16）
- ゾンビの掴み・噛みつき（05 ⑪）と同期して再生する。噛みつきを行うのは、05 §1-1-2 で「あり」のタイプだけ。移動方式は同期（スクリプトでゾンビとの位置と向きを合わせる）。

| 段階 | プレイヤー | ゾンビ |
|---|---|---|
| 掴まれる | Grab_Front_Start | Z_Bite_Start |
| もがく（ボタン連打で抵抗） | Grab_Struggle_Loop | Z_Bite_Hold |
| 抵抗に成功 | Grab_Escape（ゾンビを吹き飛ばす） | Z_Bite_Pushed |
| 抵抗に失敗 | Grab_Bitten（噛まれてダメージ） | Z_Bite_Success |

- 武器：拳銃・ナイフは利き手に持ったまま、長物などは体とゾンビの間に挟んで押し返す（Carry の変形）。
- まず正面から掴まれるパターンを作り、背後からのパターンは優先度 C とする。
- 抵抗の受付時間は約2秒（D-37）。時間の内訳は 05 ⑪ を参照。

### ㉖ 疲労
- スタミナが切れたら疲労状態に入る。Tired_Idle（膝に手をついて息を整える）と Tired_Walk を使う。
- 疲労状態ではダッシュできない。スタミナは毎秒3でゆっくり回復し、30以上になったら解除する（D-54）。
- 疲労状態（スタミナ0で起きるゲーム上の状態）と、激しい呼吸（ダッシュによる息切れのサウンド）は別の状態。
- 疲労状態では、忍び歩きと同じ速度で移動する（ゲーム仕様書 §17）。立ったまま息を切らせてゆっくり歩く Tired_Walk を前後左右で作る。
- 疲労状態の間も呼吸のサウンドは鳴り続ける。疲労が解除された後も、呼吸音の解除条件（06 §6）を満たすまで鳴らす。

### ㉗ 体術（D-16、D-27）
- 体勢崩し状態のゾンビが一定距離内にいるとき、体術キーで発動する（04 §8）。
- 移動方式は同期（ゾンビとの位置と向きを合わせる）。体術中は通常の攻撃処理を行わない。
- 技は、ゾンビの崩れた姿勢で決まる（05 ⑯・⑰と対応）。どの武器を持っていても使えるよう、脚と体を使う技にする。

  | ゾンビの状態 | 崩れた部位 | 体術 | クリップ |
  |---|---|---|---|
  | 膝をついて怯む | 頭 | 回し蹴り | Takedown_Head |
  | 上半身をのけぞらせて怯む | 肩 | 体当たり | Takedown_Shoulder |
  | うずくまって怯む | 腰 | 前蹴り | Takedown_Waist |
  | ふらついて怯む | 足 | 足払い | Takedown_Leg |
  | 倒れて怯む | ― | 踏みつけ | Takedown_Stomp |

- 武器：構え（Ready）を維持する。体当たりのときだけ、長物などは Carry にする。
- 体術のダメージ・ノックバック・転倒の効果は別途設定する。
- ゾンビのタイプで体格が違うため、体術はタイプごとに作る（人型標準・タンク型・カエル・動物の4セット。05 §1-1-2）。どのゾンビに体術をかけたかで、再生するアニメーションを切り替える（D-49）。

### ㉘ 押しのけ（D-16）
- 体勢が崩れていないゾンビが近すぎるときに、反対の腕と肩で押し返して距離を取る。
- ループしない、移動方式は RM（小さく踏み込む）、長さ 18f【暫定】。スタミナを消費する。
- 体術と同じボタンにして、「体勢崩し中なら体術、そうでなければ押しのけ」にする案がある。操作はゲーム側で決める。

### ㉚ 拾う（D-16）
- 探索で武器やアイテムを入手するときに使う。床の高さ（Pickup_Low）と腰の高さ（Pickup_Mid）の2種類。
- ループしない、移動方式はその場、長さ 18〜24f。拾う間は移動できない。回避でキャンセルできる。

### ㉛ インタラクト（D-16）
- ドアを押し開ける（Interact_Push）、装置を操作する（Interact_Use）。上半身レイヤーで行う。

### ㉜ 負傷（D-16）
- HP が一定以下になったら、Injured（加算。前かがみになり片脚をかばう）を重ね、移動速度を下げる。
- 加算方式にして、負傷時用の移動アニメーション一式を作らずに済ませる。

### ㉝ トラップ設置（D-13）
- しゃがんで地面に置く。ループしない、移動方式はその場、長さ 60f（2.0秒。ゲーム仕様書のトラップ・回復アイテム一律2秒に合わせた）。設置中は移動できない。
- 回避でキャンセルできる。Trap_Set イベントより前にキャンセルした場合、トラップは消費されない。

## 7. 8方向化のチェック項目（01 §2-5 と連動）

4方向版の Blend Tree で、以下を確認してから8方向を追加する。
- 斜め前・斜め後ろへ移動したときに足が交差しないか（半身の構えでは、利き手側の斜め後ろが特に交差しやすい）。
- 足が地面の上を滑っていないか（アニメの歩幅と実際の移動速度が合っているか）。
- 方向を切り替えたときに、上半身の武器の位置が揺れないか。
- 方向を切り替えたときに、半身の角度が変わって見えないか。

## 8. Aim / Fire（D-56 で決定）

| 項目 | 内容 |
|---|---|
| 構え（Ready）とエイム（Aim）の違い | 常にストレイフのため、エイムは「銃を目線の高さへ上げ、カメラが肩越しに寄って精密に狙う状態」とする |
| 小さい銃（拳銃・マグナム・リボルバー） | 両手を前に出して構える |
| 大きい銃（アサルトライフル・スナイパーライフルなどの長物） | 肩で銃を固定し、利き手でトリガー部分を握り、反対の手で銃口側を支える |
| 上下の照準 | **腕と頭だけを動かす。背骨は動かさない。** 各クラスの Aim を「上・正面・下」の3ポーズで作り、照準の上下の角度で Blend Tree により混ぜる（Avatar Mask は腕と頭） |
| 照準のブレ | 無し。照準はどのキャラクターも常に固定 |
| 射撃の反動 | 銃ごとに変える。基本は威力が大きいほど反動も大きくするが、具体的な大きさは武器ごとに後で調整する。加算の Fire クリップの強さと、スクリプトによるカメラの跳ね上がりで表現する |
| 弾の発射（D-25） | 弾は銃口から、射撃を入力した瞬間の照準点へ向けて飛ぶ |
| 腰だめ撃ち | 可能。レティクルを広げ、弾のばらつきを大きくする（D-38、§6 ⑯） |
| Aim への移行時間（Claude が決定） | 軽い武器 0.15秒（5f）、中程度 0.2秒（6f）、重い武器 0.25秒（8f）【暫定。操作感を見て調整】 |
| スナイパーのスコープ | FPS のようにスコープ内のレティクルと周囲の環境だけを表示し、キャラクターは表示しない（D-40）。倍率は 04 §3-6 |
| ジャンプ中 | 腰だめ撃ちのみ。エイム中にジャンプしたらエイムを解除する（D-39） |

- クラスごとの Aim は「上・正面・下」の3本になるため、§4・§5 の H_Aim / R_Aim / L_Aim はそれぞれ3本とする。
