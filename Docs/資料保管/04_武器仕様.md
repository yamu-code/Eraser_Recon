## 1. 装備の構成

| 枠 | 内容 |
|---|---|
| 常時装備 | 無限ピストル / ナイフ / 手榴弾 |
| 戦闘用武器 | 2枠。探索で入手した武器から選ぶ。選ぶ武器によってプレイスタイルが変わる |

- ナイフは独立した武器で、他の武器と同時には使えない。
- プレイヤーは常に何かの武器を持っている。素手の状態は作らない（D-20）。

## 2. 武器共通の仕様

武器ごとに次の値を設定する。
- ダメージ（1発または1回の攻撃ごと）
- ヘッドショット倍率
- 装填弾数
- 連射速度（または次の発射までの時間）
- 弾速
- 射程
- リロード時間
- ノックバック性能
- 部位怯み性能
- 音の大きさ

レベルによる強化は §11 のルールに従う。

## 4. リロード
- 銃器には装填弾数を設定する。装填弾数を使い切るとリロードが必要になる。
- リロード性能は武器ごとに異なる。
- リロード中は攻撃できない。移動はできる。
- 回避を入力すると、リロードをキャンセルして回避へ移る。

## 5. レティクル
| 武器 | レティクル |
|---|---|
| 銃器 | 固定 |
| 手榴弾 | 固定 |
| ナイフ | 攻撃ボタンを押しながら、マウスやスティックで**斬る方向**を指定し、攻撃入力で確定する（D-24） |
| 銃器の腰だめ撃ち（エイムしていないとき） | レティクルを大きく広げ、弾のばらつきを広くする（D-38） |

## 6. 射撃・弾道
- 射撃武器は即着弾ではない。発射後、弾が飛んでから命中するため、距離によって着弾までの時間が変わる。
- 移動中のゾンビには、弾速を考慮した射撃が必要になる。
- 弾速・弾道特性・偏差量は武器ごとに異なる。偏差量は、距離や武器の性能によっても変わる。
- 完全なレーザーのような直線射撃ではない（レーザーガンを除く）。
- 弓など一部の武器は、チャージ段階によって弾道が変わる。
- **偏差の定義（D-29）**：弾が重力で落ちるため、距離に応じて高さなどを先読みして狙う必要がある量。偏差が大きい武器ほど、遠くを狙うときに照準を上にずらす必要がある。
- 射程を超えた弾は消える（画面から消す）（D-35）。

## 7. ダメージ判定・部位怯み
- ダメージは武器ごとに異なる。弾や攻撃がゾンビに命中するとダメージを与える。
- 武器には「部位怯み値」を設定し、部位ごとに怯み値が一定に達すると、ゾンビが体勢崩し状態になる。

| 部位 | 命中したときの結果 | 体勢崩しの姿勢（05 と連動） | 体術 |
|---|---|---|---|
| 頭（致死） | ヘッドショット死亡。Headshot Death を他より優先して再生する（頭部が体から分離し、頭部が無い状態で倒れる） | ― | ― |
| 頭（非致死） | 怯みやすい。一定以上のダメージで大きく怯む | 膝をつく | 回し蹴り |
| 肩 | 一定以上の怯み値で上半身が崩れる | 上半身をのけぞらせる | 体当たり |
| 腰 | 一定以上の怯み値で体全体のバランスを崩す | うずくまる | 前蹴り |
| 足 | 一定以上の怯み値で足を崩す。移動能力が下がる | ふらつく | 足払い |
| （転倒） | ノックバックや体術で倒れる | 倒れる | 踏みつけ |

## 8. 体術連携
- 部位攻撃によって、ゾンビが体勢崩し状態になる場合がある。
- 体勢崩し状態の間は、特定のキーで体術を発動できる。発動には、ゾンビから一定距離以内にいる必要がある。
- 受付時間は、ゾンビが体勢を崩した時点から設定する。受付時間が過ぎると、ゾンビは通常状態に戻る。
- 体術によるダメージ・ノックバック・転倒の効果は別途設定する。
- 体術中は通常の攻撃を行わない。体術が終わると、ゾンビの AI に戻る。

## 9. ノックバック
- ノックバック性能は武器ごとに、ノックバック耐性はゾンビの種類ごとに異なる。
- 攻撃部位によって体勢の崩れ方が異なる。ショットガンなどはノックバック性能が高い。
- ノックバックでゾンビが体勢を崩す場合がある。一定の条件を満たすと、ノックバックから体術へ連携できる。

## 10. 武器バランスの基本方針

| 武器 | 役割 |
|---|---|
| 無限ピストル | 安定・節約 |
| ショットガン | 近距離・制圧・ノックバック |
| サブマシンガン | 高連射・高DPS・弾薬消費 |
| アサルトライフル | 中距離・万能 |
| マグナム／リボルバー | 単発・高火力・精密 |
| スナイパーライフル | 遠距離・部位狙い・ヘッドショット |
| ロケットランチャー | 範囲・群れ・ボス |
| レーザーガン | 貫通・高精度・一撃高火力 |
| 弓 | 静音・精密・チャージ |

- 武器を攻撃力だけで差別化しない。距離・弾速・弾道・偏差・連射性能・射程・ノックバック・部位怯み・音を組み合わせて、武器ごとの役割を作る。
- 「どの武器を使うか」だけでなく、「どの部位を狙うか」「どの距離で戦うか」「怯ませて体術へ繋げるか」まで含めて、戦闘の判断をさせる。

## 11. 武器レベル強化
- 武器ごとにレベルを設定する。レベルが上がると、武器ごとに決めた3項目が強化される。
- タイプ別の強化項目は設定しない。同じ武器の種類なら、タイプが違っても強化の仕組みは共通。
- レベルアップで、武器の基本仕様・攻撃方式・タイプは変わらない。強化対象の3項目以外は変わらない。
- 目的は「その武器を単純に強くする」こと。タイプごとの性能差は初期性能で決まる。

| 武器 | 強化する3項目 |
|---|---|
| 無限ピストル、ショットガン、サブマシンガン、アサルトライフル、マグナム、リボルバー、スナイパーライフル | ダメージ / リロード速度 / 装填弾数 |
| ロケットランチャー、弓（装填弾数を設定できない武器） | ダメージ / リロード速度 / 弾速 |
| レーザーガン（D-31） | ダメージ / 発射遅延（撃つボタンを押してから発射までの時間）の短縮 / クールタイム（次の発射まで）の短縮 |

| 強化項目 | 効果 |
|---|---|
| ダメージ | 攻撃力が上がる |
| リロード速度 | リロード時間が短くなる |
| 装填弾数 | 最大装填数が増える |
| 弾速 | 弾の飛ぶ速さが上がる |
| 発射遅延 | 撃つボタンを押してから発射までの時間が短くなる（レーザーガン） |
| クールタイム | 次に撃てるまでの時間が短くなる（レーザーガン） |

- レベルアップで変わらないもの：ヘッドショット倍率、射程、ノックバック、部位怯み、連射速度、弾道・偏差、チャージの段階と構造、武器のタイプと攻撃方式。
- 具体的なレベル数と、各レベルの強化値は別途確定する。
- ロケットランチャーと弓は装填1発のため、装填弾数ではなく弾速を強化する。弓の「リロード速度」は、次の矢を番える速さとする。

## 12. 射撃の実装方針（D-25）
- 弾は**銃口（Weapon_Muzzle）から発射する**。
- 弾が向かう先は、**射撃を入力した瞬間の照準点**とする。照準点は、カメラの中心から Raycast して求める。
- 弾速がある武器は、弾を Raycast ではなく、フレームごとに移動と当たり判定を行う方式で処理する。
- カメラと銃口の位置がずれているため、壁際では「レティクルは敵に合っているのに、銃口の前の壁に当たる」ことがある。その状態をレティクルの表示で知らせる。

### 13-2 重量による補正【暫定】
| 重量 | 武器 | 移動速度の倍率 | エイムへの移行時間 |
|---|---|---|---|
| 軽 | 拳銃、ナイフ、サブマシンガン、弓 | 1.00 | 0.15秒 |
| 中 | ショットガン、アサルトライフル、レーザーガン | 0.95 | 0.2秒 |
| 重 | スナイパーライフル、ロケットランチャー | 0.85 | 0.25秒 |

- 照準は全キャラクター共通で固定し、重さや経験によって揺らさない（D-56）。

- 移動アニメーションは重量ごとに作らない。再生速度の変更（0.85倍まで）で対応する。

### 13-3 クラスごとに必要なアニメーション
| 種類 | クラス共通（1クラスに1本） | 武器ごと |
|---|---|---|
| 構え（Ready）、エイム（Aim）、取り出し（Draw）、収納（Holster）、抱え込み（Carry） | ○ | ― |
| 射撃（Fire） | ― | ○（反動の大きさ、コッキング、ボルト操作など。反動は基本的に威力が大きいほど大きくし、武器ごとに後で調整する） |
| リロード | ― | ○（武器ごとに専用。タイプ違いは共用） |
| 特殊動作 | ― | レーザーの発射準備、弓の引き・保持・番えるなど |

- Unity では武器ごとに Animator Override Controller を用意し、Animator の構造は1つのまま、クリップだけを差し替える。
- 武器モデルの握り位置のずれ（サブマシンガンのストックが短いなど）は、武器プレハブの Weapon_Grip の位置で吸収し、アニメーションを分けない。

### 13-4 時間とアニメーションの長さを合わせるルール
- リロード時間・次の発射までの時間は、武器のタイプやレベルによって変わる。アニメーションはタイプごとに作らず、**再生速度で時間に合わせる**。
  - 再生速度 ＝ アニメーションの長さ ÷ 実際のリロード時間（Animator の Speed Multiplier パラメータで指定）
- 再生速度が 0.7〜1.5倍の範囲を超える場合は、別のアニメーションを作ることを検討する。

### 13-5 未定の武器（ゲーム仕様書 §7.8）
- ゲーム仕様書の特殊武器のうち、火薬強化兵器（クラスター弾・時限爆薬）と物理制御兵器（ワイヤー射出・地形固定）は、数値設定に含まれていない。採用するか、どの持ち方クラスにするかは保留（Q-50）。

## 14. 武器ごとのアニメーション上の特記事項

| 武器 | 特記事項 |
|---|---|
| 無限ピストル | マガジン交換のリロード（2.5秒） |
| マグナム／リボルバー | シリンダーを振り出して、スピードローダーで装填する。2タイプで同じアニメーションを使う（1.8秒 / 2秒） |
| ショットガン | 1発ずつ込めるリロードを「開始・装填ループ（1発0.6秒＝18f）・終了」の3本に分ける。途中でキャンセルすると、込めた分だけ装填される。空の状態からリロードしたときだけ、終了の後にコッキング（SG_Cock）を入れる |
| サブマシンガン／アサルトライフル | 連射中は反動を加算で重ねてループさせる。ラピッド型は、反動の加算とは別に、カメラをスクリプトで上へずらす |
| スナイパーライフル | スタンダード：セミオート（反動のみ）。高性能型：射撃ごとにボルト操作（SR_Bolt）。一撃型：1発ごとにリロード。スコープを覗いている間はキャラクターを表示しないため、覗く動作は構えから目の高さへ上げる短い遷移だけ作る |
| ロケットランチャー | 射撃時の大きな反動（体ごと少し下がる）。1発ずつ装填する |
| レーザーガン | 発射準備（約1秒。レベルで短縮されるため再生速度で合わせる）→ 照射 → クールタイム中の冷却動作 |
| 弓 | 引く（段階に応じて引き量が増える）→ 最大引きで保持（経験の浅さを出すため、腕が震える）→ 放つ → 次の矢を番える |
| 手榴弾 | 常時装備。専用ボタンで、今持っている武器のまま投げる（武器は反対の手へ持ち替える） |

## 15. 収納位置と武器の表示（D-22）

武器は全て体に表示する。

| 武器 | 収納位置 |
|---|---|
| 無限ピストル | 利き手側の太もものホルスター |
| マグナム／リボルバー | 腰の後ろのホルスター |
| ナイフ | 胸ハーネスの、利き手と反対側（鞘） |
| 手榴弾 | ベルトの、利き手と反対側のポーチ |
| 長物・ランチャー・弓（戦闘用武器の2枠） | 背中。1枠目は斜め掛け、2枠目はバックパックの横に縦に吊るす【暫定】 |

- 収納位置は Unity 側のソケット（空の GameObject）で管理する（02 §8-4）。
- ライト（常時装備）は、手の甲か武器に付ける（D-64）。武器に付ける場合、各武器プレハブに取り付け位置（Light_Mount）を用意する。ナイフや弓など、付けられない武器を持っているときは手の甲に付ける【暫定】。
- 武器の大きさは男女で変える（D-23）。キャラクターごとに武器プレハブのバリエーションを作り、大きさと握り位置（Weapon_Grip）を調整する。
