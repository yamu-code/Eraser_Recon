# Eraser Recon 操作設定（ボタン配置）

- 最終更新：2026-10-12（パターンBのダッシュをL3→△に変更）
- 正本の仕様は [GameSpec.md](./GameSpec.md)（移動の「操作」節と §8.0）。この資料は、ボタン配置を一覧で見られるようにまとめたもの。
- コントローラーは**設定で4パターンから選べる**。初期設定は**スタンダード**。
- ボタン表記は PlayStation（括弧内は Xbox）。

---

## 1. ダッシュ方式

| 方式 | 動き | 良いところ | 気をつけるところ |
|---|---|---|---|
| **ホールド** | 押している間だけダッシュ。離すと止まる | すぐ止まれる。誤って押しても一瞬で止まる | 長く走ると指が疲れる |
| **トグル** | 1回押すとダッシュ開始、**もう一度押すとダッシュ解除**（1つのボタン／キーでオン・オフ） | 押し続けなくていいので指が楽 | 誤って押すと走り続け、足音・スタミナを無駄にする |

**トグルの解除条件**：**ダッシュボタンをもう一度押す**／止まる（スティックをほぼ戻す）／しゃがむ／Ctrl（キーボード）で忍び歩き／疲労状態になる

**L3でダッシュするときのルール（スティックの倒し具合との衝突対策）**
- L3はスティックを押し込むボタンなので、押し込むときに倒し具合が一瞬ゆるみ、「少しだけ倒す＝忍び歩き」と誤判定されることがある。
- 対策として、**ダッシュの入力中（ホールド中・トグルON中）は、スティックの倒し具合による忍び歩き判定を無視する**。走りたいという意思を優先する。
- ダッシュ入力中でも、止まる（スティックをほぼ戻す）・しゃがむ・疲労状態 は優先される。
- ダッシュしていないときの「忍び歩き⇔通常歩行」の境目には、入る/抜けるしきい値をずらす処理（ヒステリシス）を入れてチラつきを防ぐ。

## 2. 全パターン共通のボタン

| ボタン | 操作 |
|---|---|
| 左スティック | 移動（少しだけ倒すと忍び歩き） |
| 右スティック | 視点操作 |
| L2（LT） | 構える（トラップモードでは設置場所を表示） |
| R2（RT） | 撃つ・使う・設置する（モードによって変わる） |
| L1（LB） | 今のモードの左のスロットを選ぶ |
| R1（RB） | 今のモードの右のスロットを選ぶ |
| □（X） | リロード |
| R3 | しゃがむ／立つ（切り替え） |
| 十字キー上／下 | モード切替（下＝回復／中＝武器／上＝トラップ） |
| タッチパッド（ビュー） | マップ |
| オプション（メニュー） | ポーズ |

- モード切替は武器モードを含めた3段。回復モードなら上で武器モード、トラップモードなら下で武器モードに戻る。

## 3. パターン別のボタン配置

各パターンの表は、共通のボタンも含めた**全ボタン**を載せている（その表だけで配置が分かるように）。**太字**はパターンによって変わるボタン。

### スタンダード（初期設定）：普通持ち・ホールド

| ボタン | 操作 |
|---|---|
| 左スティック | 移動（少しだけ倒すと忍び歩き） |
| 右スティック | 視点操作 |
| L2（LT） | 構える |
| R2（RT） | 撃つ・使う・設置する |
| L1（LB）／R1（RB） | 今のモードの左／右のスロットを選ぶ |
| **△（Y）** | **ナイフ持ち替え** |
| ○（B） | インタラクト |
| **×（A）** | **回避（スティックを倒した方向に転がる）** |
| □（X） | リロード |
| **L3** | **ダッシュ（押している間）** |
| R3 | しゃがむ／立つ |
| 十字キー上／下 | モード切替 |
| **十字キー左** | **インベントリ** |
| **十字キー右** | **空き** |
| タッチパッド（ビュー） | マップ |
| オプション（メニュー） | ポーズ |

**この配置の理由**
- 普通持ちでは右手の親指がカメラ（右スティック）の上にある。押し続けるダッシュをフェイスボタンに置くと走っている間カメラが止まるため、左手の親指で押せる L3 に置いた。
- 回避は一番急ぐ操作なので、親指で一番押しやすい × に置いた。左手はスティックに残るので転がる方向を選べる。

| **△（Y）** | **ダッシュ（押している間）** |
| ○（B） | インタラクト |

**この配置の理由**
- ダッシュは△を人差し指で押し続ける。両手の親指がスティックに残るので、走りながら曲がれる。（2026-10-12：一度L3にしたが、実機テストでL3を押し込みながらの移動が難しかったため△に戻した）
- ×はモンハン持ち・普通持ちのどちらでも押しにくいため、あまり使わないナイフ持ち替えに置いた。
- 回避は十字キーなので、押す瞬間は左手の親指がスティックから離れ、向いている方向にしか転がれない。

- インタラクトは落ち着いているときに押す操作なので、親指で押す×に置いた。

## 6. ボタンを置かないと決めたもの

- **クイックターン**：右スティックで自由にカメラを回せるため不要。遊んでみて振り向きが遅いと感じたら追加を検討。
- **懐中電灯**：暗いエリアに入ると自動で点灯（ゾンビは視覚をほぼ使わないため、手動で消す駆け引きが不要）。

## 7. 実装メモ

- ボタンの違いは Input System の**バインディンググループ**でパターンごとに登録し、設定で切り替える。
- ダッシュ方式の違い（ホールド／トグル）はスクリプト側の設定で切り替える。
- 最初に実装するのはスタンダード。ほかのパターンは設定画面を作るときに追加する。
